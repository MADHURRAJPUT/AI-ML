# 3.5 pandas & Matplotlib — the exploratory data analysis workflow

Real ML work is mostly data work. Before any model, you need to answer: *what's
in this table, what's broken, and what relates to the target?* This lesson is a
complete EDA workflow on a realistic, deliberately messy **customer-churn**
dataset (generated by [`common/churn_data.py`](../../common/churn_data.py), so it works offline;
week 6's lessons and project reuse it).

## pandas mental model

- A **`Series`** = a 1-D NumPy array + an index (labels).
- A **`DataFrame`** = a dict of Series sharing one index — a table with typed columns.
- Most operations are **vectorised and column-wise**; looping over rows (`iterrows`) is a smell.

## The EDA checklist (do this on every new dataset)

| Step | Questions | pandas |
|---|---|---|
| 1. Load | right delimiter, types, dates parsed? | `pd.read_csv(path, parse_dates=[...])` |
| 2. Shape & types | how many rows/cols? numbers stored as strings? | `df.shape`, `df.dtypes`, `df.info()` |
| 3. Peek | what do rows look like? | `df.head()`, `df.sample(5)` |
| 4. Missing values | where, how many, random or systematic? | `df.isna().mean()` |
| 5. Duplicates | repeated rows / IDs? | `df.duplicated(subset=...).sum()` |
| 6. Summary stats | ranges, impossible values, outliers? | `df.describe()`, `.quantile([.01,.99])` |
| 7. Categoricals | cardinality, typos, inconsistent case? | `df[c].value_counts()`, `.str.lower().str.strip()` |
| 8. Target | balance? leakage suspects? | `df.target.value_counts(normalize=True)` |
| 9. Relationships | what moves the target? | `groupby(...).target.mean()`, `pd.crosstab`, `corr()` |
| 10. Plot | distributions, target vs features | histograms, box plots, bar charts of rates |

## Essential operations

```python
df.loc[rows, cols]          # label-based selection
df.iloc[0:5, 2]             # position-based selection
df[df.tenure > 12]          # boolean filtering
df.assign(x=lambda d: ...)  # add columns in a chain
df.groupby("plan").agg(churn=("churned", "mean"), n=("churned", "size"))
df.merge(other, on="customer_id", how="left", validate="one_to_one")
df.pivot_table(index="plan", columns="region", values="churned", aggfunc="mean")
pd.cut(df.age, bins=[0, 25, 40, 60, 120])      # binning
df["signup"].dt.month                           # datetime accessor
df["plan"].str.lower().str.strip()              # string accessor
```

### Pitfalls that cause real bugs

- **`SettingWithCopyWarning`** — chained indexing `df[df.a > 0]["b"] = 1` may modify a copy. Use `df.loc[df.a > 0, "b"] = 1`.
- **Silent type coercion** — one `"N/A"` string turns a numeric column into `object`. Use `pd.to_numeric(errors="coerce")` and count the NaNs it creates.
- **Merges that multiply rows** — a key duplicated on both sides yields a Cartesian product. Use `validate=`.
- **`NaN` semantics** — `NaN == NaN` is False; `mean()` skips NaNs by default; `groupby` drops NaN keys unless `dropna=False`.
- **Imputing before splitting** — using the full-data mean to fill NaNs leaks test information (week 6). In EDA, just *measure*; do fixes inside a pipeline later.

## Matplotlib in 60 seconds

Always use the object-oriented API:

```python
fig, axes = plt.subplots(2, 2, figsize=(10, 8))
axes[0, 0].hist(df.monthly_charges, bins=40)
axes[0, 0].set(title="Monthly charges", xlabel="$", ylabel="count")
fig.tight_layout(); fig.savefig("eda.png", dpi=120)
```

Which plot for which question:

| Question | Plot |
|---|---|
| Distribution of one numeric feature | histogram (log-scale x if skewed) |
| Numeric feature vs binary target | overlaid histograms or box plot per class |
| Categorical feature vs binary target | bar chart of target rate per category, with counts |
| Two numerics | scatter (alpha < 1 for many points) |
| Many numeric correlations | heatmap of `df.corr()` |
| Over time | line plot of a resampled rate (`df.resample("M", on="date")`) |
